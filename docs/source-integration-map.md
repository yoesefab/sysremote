# Source Integration Map

This file records where every teammate source file went before the owner
folders were removed.

## Wafae

- `bin/sysremote.sh` -> merged into `bin/sysremote.sh`.
- `lib/*.sh` -> merged into `lib/cli.sh`, `lib/commands.sh`, `lib/config.sh`,
  `lib/defaults.sh`, `lib/remote.sh`, `lib/targets.sh`, `lib/ui.sh`,
  `lib/utils.sh`, and `lib/validation.sh`.
- `sysremote_fork.c` -> integrated as `modules/native/sysremote_fork.c` with
  safer log-directory creation and safe log filenames.
- `sysremote_thread.c` -> integrated as `modules/native/sysremote_thread.c`;
  local `system()` command construction was replaced with fork/exec.
- `sysremote_parallel.sh` -> integrated as `tools/native_parallel.sh`.
- `benchmark.sh` -> integrated as `tools/native_benchmark.sh`; the main CLI
  also exposes `benchmark`.
- `Makefile` -> merged into the root `Makefile` as `native`, `native-check`,
  and `native-clean` targets.
- `docs/rapport-shell.md`, `docs/tests-manuels.md`, `docs/usage-rapide.md`
  -> moved into `docs/`.
- `tools/make_deliverables.py` -> moved into `tools/`.
- `hosts.txt` -> moved into `examples/hosts.txt`.
- `inventory.example` and `sysremote.conf.example` -> merged into root examples.
- `test.txt` -> moved into `examples/test-lot3.txt`.
- compiled `sysremote_fork` and `sysremote_thread` -> regenerated by
  `make native` into `build/native/`, not stored as source.

## Youssef

- The duplicate base CLI files were compared with Wafae's base and merged into
  the final `bin/` and `lib/` implementation.
- `docs/*`, `inventory.example`, and `sysremote.conf.example` were merged into
  the final root docs and examples.
- `tools/make_deliverables.py` was represented by the final `tools/` copy.

## Soukaina

- `sysremote.sh.txt` -> command surface merged into the unified CLI.
- `lib/common.sh.txt` -> logging, errors, dependency checks, and execution mode
  ideas merged into `lib/ui.sh`, `lib/utils.sh`, `lib/defaults.sh`, and
  `lib/remote.sh`.
- `lib/backup.sh.txt` -> `modules/backup.sh`.
- `lib/restore.sh.txt` -> `modules/restore.sh`.
- `lib/audit.sh.txt` -> `modules/audit.sh`.
- `lib/mantain.sh.txt` -> `modules/maintenance.sh`.
- `lib/schedule.sh.txt` -> `modules/schedule.sh`.
- `README.md` and `guide_test_sysremote.md` -> integrated as
  `docs/backup-restore-audit-tests.md` plus root README command coverage.

## Salma

- `monitoring.sh` -> `modules/monitoring.sh`, adapted to the shared config,
  target loading, SSH executor, logger, dry-run, and report paths.
- `sysremote.conf.example` -> monitoring keys merged into
  `sysremote.conf.example`.
- `README.md` -> `docs/monitoring-alerting-reporting.md`.

## Final Runtime Rule

Only the root project is runtime-active. The old owner folders were removed
after their features, docs, examples, and optional native sources were mapped
into the final structure.
